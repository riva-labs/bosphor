---
title: Quote without a wallet on your backend
description: Serve live EVM and Solana storage prices from a server route with quoteEvmStore and quoteSolanaStore, no keys or wallet needed.
---

Show a price on a pricing page, in a checkout summary, or before a user connects
a wallet. `quoteEvmStore()` needs only a read-only RPC provider (it reads the
live LayerZero fee from the adapter), and `quoteSolanaStore()` needs nothing at
all: the relayer simulates the live Solana LayerZero fee for it. Both ask the
relayer for the storage price. The result is the same `PricedQuote` that `client.priceQuote()`
returns, so what you show matches what the user pays.

## Install

```bash
npm install @bosphor/sdk ethers
```

## The route

```ts title="app/api/quote/route.ts"
import { JsonRpcProvider } from "ethers";
import { RelayerRequestError, TESTNET, quoteEvmStore, type PricedQuote } from "@bosphor/sdk/evm";
import { quoteSolanaStore } from "@bosphor/sdk/solana";

// Created once and reused across requests. Bring your own RPC URL in production.
const provider = new JsonRpcProvider(process.env.SEPOLIA_RPC_URL ?? TESTNET.evm.rpcUrl);

/** bigint amounts do not survive JSON.stringify: send them as decimal strings. */
function toJson(quote: PricedQuote) {
  return {
    token: quote.originToken,
    total: quote.totalNative.toString(),
    escrow: quote.escrowNative.toString(),
    forward: quote.forwardNative.toString(),
    forwardIsUpperBound: quote.forwardIsUpperBound,
    totalUsd: quote.breakdown.totalUsd,
  };
}

/**
 * GET /quote?chain=evm|solana&size=<bytes>&epochs=<n>
 * A standard Request -> Response handler: works as a Next.js route handler,
 * a Cloudflare Worker, Bun, Deno, or Hono.
 */
export async function GET(request: Request): Promise<Response> {
  const url = new URL(request.url);
  const chain = url.searchParams.get("chain") ?? "evm";
  const sizeBytes = Number(url.searchParams.get("size"));
  const epochs = Number(url.searchParams.get("epochs") ?? 5);
  if (!Number.isInteger(sizeBytes) || sizeBytes <= 0) {
    return Response.json({ error: "size must be a positive integer" }, { status: 400 });
  }

  let quote: PricedQuote;
  try {
    quote =
      chain === "solana"
        ? await quoteSolanaStore({ sizeBytes, epochs, appId: "my-dapp" })
        : await quoteEvmStore({ provider, sizeBytes, epochs, appId: "my-dapp" });
  } catch (err) {
    // Rate limited or busy relayer: pass its Retry-After on to your client.
    if (err instanceof RelayerRequestError && err.retryable) {
      const seconds = Math.ceil((err.retryAfterMs ?? 5_000) / 1000);
      return Response.json(
        { error: "the relayer is busy, try again shortly" },
        { status: 503, headers: { "retry-after": String(seconds) } },
      );
    }
    throw err;
  }

  return Response.json(toJson(quote), {
    // Prices move with gas and token prices: cache briefly, not for long.
    headers: { "cache-control": "public, max-age=30" },
  });
}
```

Call it with `GET /api/quote?chain=evm&size=1048576`. The response looks like:

```json
{
  "token": "ETH",
  "total": "1267781979879960",
  "escrow": "968314000000000",
  "forward": "299467979879960",
  "forwardIsUpperBound": false,
  "totalUsd": 3.4095
}
```

## Notes

- **Size, not bytes.** Pass `sizeBytes` when you only know the size, or `data`
  to price exact bytes. The price depends only on the size.
- **Amounts are strings.** Amounts are in the smallest unit (wei or lamports).
  Format them in the client with `formatEther` or by dividing by
  `LAMPORTS_PER_SOL`.
- **Exact Solana fee.** From `@bosphor/sdk` 0.14.0 the Solana LayerZero fee
  comes from the relayer (`GET /lz-fee/solana`) when the optional
  `@layerzerolabs/lz-solana-sdk-v2` is not installed, so `forwardIsUpperBound`
  is `false`. It is `true` only against a relayer without that endpoint; show
  that total as "up to".
- **Rate limits.** The relayer limits `/quote` per IP. Cache briefly on your
  server rather than quoting on every keystroke. See
  [Rate limits](/docs/api#rate-limits).
- **Quotes move.** Gas and token prices change, so quote again right before the
  user pays. `storePriced()` and `priceQuote()` always fetch a fresh one.
