Everything here runs against the hosted testnet, so there is nothing to deploy.
Bring a funded Sepolia or Solana devnet wallet (see
[Fund your wallet](/docs/quickstart#fund-your-wallet)). Filter by chain or by kind
of example:

- **Starters** are standalone repos: clone, `npm install`, fill in `.env`, run.
- **Scripts** are single files in the SDK repo. Run them from `sdk/` with
  `node --import tsx examples/<script>`.
- **Reference integrations** are live apps built on the SDK.
- **Recipes** are short, focused pages with code you can paste. Every recipe
  type-checks against the published `@bosphor/sdk`.
