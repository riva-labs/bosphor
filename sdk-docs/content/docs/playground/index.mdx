Try Bosphor without writing code. Price any file on the hosted testnet with no wallet,
see the SDK call that does the same thing, then optionally connect a Sepolia wallet
and run a real store: pay once, watch LayerZero carry the intent to Sui, the relayer
store the file on Walrus, and the proof come back.

## What the numbers mean

The quote is one amount in the origin chain's native token. It has two parts:

- **Escrow**: Walrus storage, Sui gas, the LayerZero fee for the proof's return
  trip, a price buffer, and the service margin. It is held by the adapter and
  released to the relayer only when the storage proof arrives, or refunded after
  the deadline if it never does.
- **LayerZero forward fee**: paid to LayerZero at submit to carry the intent to Sui.

On Solana, this page prices the forward fee at the preset cap, because the live fee
needs the optional `@layerzerolabs/lz-solana-sdk-v2` package. The amount actually
charged is lower. See [What the quote contains](/docs/guides/pay-for-storage#what-the-quote-contains) for the full
pricing model.

