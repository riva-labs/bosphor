The failures you will actually hit, and what to do about each. See
[Handle errors](/docs/errors) for the typed-error model and
[Resume after a crash](/docs/resume) for recovery.

## `upload` fails with a 404 right after `submit`

The relayer only accepts bytes once its watcher has seen your on-chain intent, a
short lag after you submit. `store()` retries past that window internally. If you
drive the steps yourself, retry the upload rather than failing the flow.

## `ProofTimeoutError`, is my file lost?

No. It means the proof had not landed **yet**, not that the intent failed. The
intent is on-chain and the bytes are with the relayer, so re-poll:

```ts
const { blobId, endEpoch } = await client.awaitProof(intentId, { timeoutMs: 300_000 });
```

## Does the SDK ever see my private key?

No. The EVM client works through an `ethers` **signer**; the Solana client takes
a wallet. Signing stays in your wallet, so browser wallet
integrations and sponsored (gasless) transactions work unchanged.

## Blob-id mismatch

The blob id the SDK commits to on-chain must equal the id the relayer recomputes
from the uploaded bytes. A mismatch means the uploaded bytes differ from the
encoded bytes, or a custom `computeBlob` returned a different id. Use the same
bytes and the same `computeBlob` end to end.

## Can I use the SDK on mainnet?

Not yet. There is no mainnet deployment. The default `computeBlob` is fixed to
testnet Walrus parameters; for mainnet, inject your own `computeBlob` and point
the client at your own adapter. See [Store from EVM](/docs/evm#blob-id-computation).

## How much does a store cost on testnet?

At current prices, a paid store of a 1 KB file for 5 epochs costs about 0.0015 ETH
on Sepolia, or about 0.035 SOL on Solana devnet including account rent. Prices
follow live token prices, so ask for a live number with `client.priceQuote(encoded)`.
See [Pay for storage](/docs/pay-for-storage).

## `quote` or `submitIntent` reverts on EVM

Two common causes:

- **Empty LayerZero options.** The adapter needs executor options; `0x` makes the
  quote revert. `createBosphorClientFromSigner` passes `TESTNET.evm.lzOptions` for
  you; if you wire the client by hand, pass `options: TESTNET.evm.lzOptions`.
- **`InsufficientPayment`.** `msg.value` was below the LayerZero fee. Use
  `storePriced()` / `submitPaid()`, or `quote()` before `submit()`.

With `ADAPTER_ABI` bound to your contract, `ethers` decodes the adapter's custom
errors by name.

## Which Node version do I need?

Node.js **22 or newer**. The SDK is ESM-only.

## `ERR_REQUIRE_ESM` / import errors

`@bosphor/sdk` is ESM-only. Use ESM (`import`), Node 22+, and `"type": "module"`
(or `.mjs`). It cannot be `require()`-d from CommonJS.
