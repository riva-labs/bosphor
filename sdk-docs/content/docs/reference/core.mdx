## fetchQuote

```ts
fetchQuote(relayerUrl: string, request: QuoteRequest, opts?: FetchQuoteOptions): Promise<PricedQuote>
```

Calls the relayer `POST /quote` endpoint and returns a typed quote. Amounts cross
the wire as decimal strings and come back as `bigint`. Throws `BosphorError` on a
non-2xx response or an unparseable body, never a fabricated price. The chain
clients wrap it as `priceQuote()`. See [Pay for storage](/docs/pay-for-storage).

## StoreProgress

The events passed to the `onProgress` option of `store()` / `storePriced()`, in
order: `encoded`, `quoted` (skipped by Solana `store()`), `submitted`, `uploaded`,
`proven`. Each carries the data known at that point, for example `txHash` on
`submitted` and `blobId`/`endEpoch` on `proven`.

```ts
type StoreProgress =
  | { step: 'encoded'; encoded: EncodedIntent }
  | { step: 'quoted'; amount: bigint; quote?: PricedQuote }
  | { step: 'submitted'; intentId: Hex; txHash: string }
  | { step: 'uploaded'; intentId: Hex }
  | { step: 'proven'; intentId: Hex; blobId: Hex; endEpoch: bigint };
```

## Errors

Every failure extends `BosphorError`. See [Handle errors](/docs/errors) for the
catch-and-narrow pattern.

| Error | Fields | Meaning |
|-------|--------|---------|
| `RelayerUploadError` | `status`, `reason`, `intentId` | The relayer rejected the out-of-band blob upload. |
| `ProofTimeoutError` | `intentId`, `timeoutMs` | The intent did not execute within the timeout; re-poll `awaitProof`. |
| `BosphorError` | `code`, `retryable` | Base class of every SDK error. |
