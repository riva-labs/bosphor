## Errors

Every failure extends `BosphorError`. See [Handle errors](/docs/errors) for the
catch-and-narrow pattern.

| Error | Fields | Meaning |
|-------|--------|---------|
| `RelayerUploadError` | `status`, `reason`, `intentId` | The relayer rejected the out-of-band blob upload. |
| `ProofTimeoutError` | `intentId`, `timeoutMs` | The intent did not execute within the timeout; re-poll `awaitProof`. |
| `BosphorError` | `code`, `retryable` | Base class of every SDK error. |
