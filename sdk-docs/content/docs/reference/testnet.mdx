Everything you need to run against testnet. These values are fixed for the
current deployment.

<Callout type="info" title="Testnet only">
These are Sepolia and Sui testnet addresses. There is no mainnet deployment yet;
for mainnet, inject your own `computeBlob` and point the client at your own
adapter. See [Store from EVM](/docs/evm#blob-id-computation).
</Callout>
