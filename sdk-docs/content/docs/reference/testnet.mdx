This page is the single up-to-date list of the hosted Bosphor testnet deployment.
The same values ship in the SDK as the `TESTNET` preset (exported from
`@bosphor/sdk`, `@bosphor/sdk/evm`, and `@bosphor/sdk/solana`), so in code you
never need to copy them.

<Callout type="info" title="Testnet only">
Mainnet is not open for integrations yet. For your own deployment, build a
network preset from `TESTNET` with your addresses; see
[Self-hosting](https://docs.bosphor.xyz/self-hosting).
</Callout>

## Using the preset

```ts
import { TESTNET, createBosphorClientFromSigner } from '@bosphor/sdk/evm';

const client = await createBosphorClientFromSigner(signer); // TESTNET is the default
console.log(TESTNET.evm.adapterAddress, TESTNET.sui.eid, TESTNET.relayerUrl);
```
