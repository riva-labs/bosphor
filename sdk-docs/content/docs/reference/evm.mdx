The EVM client wraps an `ethers` contract bound to a signer. See the
[EVM guide](/docs/evm) for usage. The tables below are generated from the SDK
source.

## BosphorEvmClient

Build one with `createBosphorClientFromSigner(signer)` (hosted testnet) or
`new BosphorEvmClient(options)`. It exposes the one-call `storePriced` and `store`,
and the individual steps.

### Methods

| Method | Signature | Returns |
|--------|-----------|---------|
| `storePriced` | `storePriced(data: Uint8Array, opts?: EncodeOptions & AwaitProofOptions & ProgressOptions)` | `Promise<StoreResult & { quote: PricedQuote }>` |
| `store` | `store(data: Uint8Array, opts?: EncodeOptions & AwaitProofOptions & ProgressOptions)` | `Promise<StoreResult>` |
| `encode` | `encode(data: Uint8Array, opts?: EncodeOptions)` | `Promise<EncodedIntent>` |
| `priceQuote` | `priceQuote(encoded: EncodedIntent, opts?: { signal?: AbortSignal })` | `Promise<PricedQuote>` |
| `submitPaid` | `submitPaid(encoded: EncodedIntent, quote: PricedQuote)` | `Promise<{ intentId: Hex; txHash: string }>` |
| `quote` | `quote(encoded: EncodedIntent)` | `Promise<MessagingFee>` |
| `submit` | `submit(encoded: EncodedIntent, fee: MessagingFee)` | `Promise<{ intentId: Hex; txHash: string }>` |
| `getEscrow` | `getEscrow(intentId: Hex)` | `Promise<EscrowRecord>` |
| `refund` | `refund(intentId: Hex)` | `Promise<{ txHash: string }>` |
| `withdraw` | `withdraw()` | `Promise<{ txHash: string }>` |
| `upload` | `upload(intentId: Hex, data: Uint8Array, opts?: { signal?: AbortSignal })` | `Promise<void>` |
| `awaitProof` | `awaitProof(intentId: Hex, opts?: AwaitProofOptions)` | `Promise<{ blobId: Hex; endEpoch: bigint }>` |

`storePriced()` runs `encode, priceQuote, submitPaid, upload, awaitProof`: it pays
`quote.escrowNative + quote.forwardNative` as `msg.value`, and the adapter escrows
everything above the LayerZero fee until the proof lands. `store()` runs
`encode, quote, submit, upload, awaitProof` and pays only the LayerZero fee. Both
resolve only once the result is verified on-chain. See
[Pay for storage](/docs/pay-for-storage).

`refund` and `withdraw` need the escrow adapter members, which `connectAdapter` /
`createBosphorClientFromSigner` bind. See [Pay for storage](/docs/pay-for-storage#refund-an-escrow).

## quoteEvmStore

```ts
quoteEvmStore(opts: QuoteEvmStoreOptions): Promise<PricedQuote>
```

Prices a store without a wallet: the live LayerZero fee from the adapter's
`quote()` view (through a read-only `provider`) plus the relayer storage price.
Pass the file as `data` (bytes) or `sizeBytes`, plus optional `epochs`, `network`,
`fetch`, `signal`, and `ethers`.

## createBosphorClientFromSigner

```ts
createBosphorClientFromSigner(signer: EthersSignerLike, opts?: CreateClientFromSignerOptions): Promise<BosphorEvmClient>
```

Builds a client from an `ethers` v6 Signer with no ABI or address wiring. Defaults
come from the `network` option (default [`TESTNET`](/docs/reference/testnet)):
the adapter address, `relayerUrl`, `dstEid` (Sui), LayerZero `options`, and the
Walrus network. `ethers` is loaded lazily as an optional peer.

## connectAdapter

```ts
connectAdapter(signer: EthersSignerLike, opts?: ConnectAdapterOptions): Promise<AdapterContract>
```

Binds the adapter (default `TESTNET.evm.adapterAddress`) to a signer with
`ADAPTER_ABI` and returns it as an `AdapterContract`, ready for `createBosphorClient`.

## ADAPTER_ABI

`readonly string[]`: the escrow adapter ABI in `ethers` human-readable form. It
covers `submitIntent`, `quote`, `getIntentId`, `nonces`, `intents`, `executed`,
`committedBlobId`, `intentDeadlines`, `trustedRelayer`, `getEscrow`, `refund`,
`withdrawable`, `withdraw`, the `IntentSubmitted`, `IntentExecuted`,
`EscrowOpened`, `EscrowReleased`, and `EscrowRefunded` events, and the custom
errors. `EscrowStatus` maps `getEscrow(...).status`: `None` 0, `Pending` 1,
`Released` 2, `Refunded` 3.

## Functions

- `createBosphorClient(options)`: factory that mirrors `new BosphorEvmClient(options)`.
- `fetchQuote(relayerUrl, request, opts?)`: the relayer quote client (see [Core](/docs/reference/core#fetchquote)).
- `walrusBlobUrl(blobId, network?)`: Walrus aggregator URL for a returned blob id.
- `fromEthersContract(contract, opts?)`: build the full `AdapterContract` (including the `queryProof` reader) from an `ethers.Contract`, so no cast or hand-written proof-log parsing is needed.
- `createDefaultComputeBlob(network)`: build the blob-id computation bound to `"testnet"` or `"mainnet"`.
- `defaultComputeBlob(data)`: the default testnet blob-id computation (lazily loads `@mysten/walrus`).
- `base64UrlToBytes32Hex(id)`: converts a base64url Walrus blob id to a `0x` hex string.
- `decodeProofEndEpoch(data)`: reads the end epoch from a returned proof payload.
