## Functions

- `createBosphorSolanaClient(options)`: factory that mirrors `new BosphorSolanaClient(options)`.
- `createDefaultSolanaChain(options)`: builds the default `SolanaChain` backend (lazily loads `@solana/web3.js`).
- `decodeIntentState(data)` / `readSolanaProof(data)`: decode the `IntentState` account bytes.
- `BOSPHOR_PROGRAM_ID`, `INTENT_STATE_LEN`: the program id and account length constants.
