# Bosphor SDK docs (sdk.bosphor.xyz)

The documentation site for [`@bosphor/sdk`](../sdk). Built with
[Starlight](https://starlight.astro.build) (Astro); the API reference is generated
from `../sdk/src` with [TypeDoc](https://typedoc.org) via `starlight-typedoc` at
build time, so it never drifts from the source.

## Structure

Content follows [Diátaxis](https://diataxis.fr): each page is one of four kinds and
does not mix them.

```
src/content/docs/
  index.mdx              # landing
  getting-started/       # tutorial: learn by doing
  guides/                # how-to: finish a specific task
  concepts/              # explanation: understand the model
  reference/             # reference: GENERATED by TypeDoc (gitignored)
```

## Local development

The API reference needs the SDK's dependencies resolvable, so install the SDK once
first:

```bash
cd ../sdk && npm install
cd ../sdk-docs && npm install
npm run dev      # local preview at http://localhost:4321
npm run build    # static build to dist/ (regenerates the API reference)
```

## Deployment

Deployed to Cloudflare Workers at **sdk.bosphor.xyz** by
`.github/workflows/sdk-docs.yml` on any push to `main` that touches `sdk-docs/**`
or `sdk/src/**`.

**One-time setup** (needs Cloudflare access):

1. Add two repository secrets (Settings → Secrets and variables → Actions):
   - `CLOUDFLARE_API_TOKEN`: a token with `Workers Scripts:Edit`.
   - `CLOUDFLARE_ACCOUNT_ID`: the account that owns the `bosphor.xyz` zone.
2. The custom domain `sdk.bosphor.xyz` is declared in `wrangler.jsonc` and is bound
   on the first deploy. Nothing else to configure.

To deploy by hand: `npm run deploy` (runs `astro build` then `wrangler deploy`).
